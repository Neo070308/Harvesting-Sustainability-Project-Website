# Harvesting Sustainability Project — Website

The website for **Harvesting Sustainability Project**, a nonprofit I founded that recovers surplus backyard produce and connects it with local food pantries. This app is the technical backbone of the organization — it's how donors list surplus produce, volunteers coordinate pickups, and the harvest booking process actually runs.

Since launching, the platform has supported **2,000+ lbs of produce donated**, helped the program expand to neighboring cities, and been covered by the *Los Altos Town Crier*.

## What it does

- Lets homeowners with surplus backyard produce submit and schedule donation pickups
- Coordinates volunteers to collect and deliver donations to local food pantries
- Streamlines the logistics that used to run manually, so the nonprofit could scale past what a few volunteers could track by hand

## Built with

- **React 18** + **TypeScript**
- **Vite** — build tooling
- **Tailwind CSS** + **shadcn/ui** (Radix UI primitives) — component library and styling
- **React Hook Form** + **Zod** — form handling and validation
- **TanStack Query** — data fetching and state management
- **React Router** — client-side routing
- **Recharts** — data visualization

## Running locally

```bash
npm install
npm run dev
```
